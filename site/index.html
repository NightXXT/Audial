O que é o Audial?

Um player de música para Windows 10 e 11, feito como app nativo do Windows (WinUI 3, sem Electron e sem aba de navegador por trás), que toca as músicas do YouTube Music. É um projeto independente, feito por uma pessoa só, e não tem ligação com o YouTube nem com o Google.

Quanto custa?

Nada. O Audial é grátis, não tem anúncios e não tem plano pago. Dá para apoiar o projeto com Pix ou Ko-fi, mas isso é opcional e não libera nada a mais: todo mundo recebe o mesmo Audial.

Como eu baixo?

Clique em Baixar grátis, abra o AudialSetup.exe e siga o instalador. Não precisa de convite nem de conta. Depois disso, o Audial se atualiza sozinho.

Preciso criar uma conta?

Não. Não existe conta no Audial. Entrar com a sua conta Google é opcional e serve apenas para ver as suas playlists e curtidas, com permissão somente de leitura. O Audial não cria, edita nem apaga nada na sua conta, e você pode sair quando quiser.

É seguro instalar?

O Audial só aceita atualização com a assinatura digital do projeto: se o instalador for alterado no caminho, o app recusa. O instalador ainda não tem certificado da Microsoft, então na primeira instalação o Windows pode mostrar “O Windows protegeu o computador”; é só clicar em “Mais informações” e depois em “Executar assim mesmo”. Baixe o Audial só pelos links oficiais, nunca de sites de terceiros.

O que o Audial sabe sobre mim?

O mínimo. Não tem anúncio, rastreamento nem ferramenta de análise. O login fica cifrado pelo próprio Windows, só no seu PC. O Audial não tem servidor nem banco de dados: o que ele guarda fica no seu PC. No Ouvir junto, os computadores se conectam direto um ao outro. Os detalhes, inclusive os seus direitos pela LGPD, estão na política de privacidade.

Tem versão para celular?

Ainda não. Por enquanto o Audial é só para Windows. Uma versão para Android está nos planos; para iPhone, não há previsão. Enquanto isso, dá para controlar o Audial do PC pelo celular.

O código é aberto?

O código do projeto fica no GitHub. Os instaladores oficiais ficam nas releases do GitHub; as mudanças mais recentes do código do aplicativo ainda não foram publicadas lá.

Como falo com o suporte?

Pelo servidor do Audial no Discord ou abrindo uma issue no GitHub. Para pedidos sobre os seus dados, mande uma mensagem direta para o criador no Discord, e não uma issue, que é pública.
